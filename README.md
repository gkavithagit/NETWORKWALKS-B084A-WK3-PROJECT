Week 3 – Password Cracking Using John the Ripper

Project Overview

As part of my Cybersecurity Internship at NetworkWalks, this Week 3 project focuses on understanding password security and password cracking techniques using John the Ripper.

The objective of this practical exercise is to understand password hashes, perform dictionary-based password testing, and explore how weak passwords can be identified in an authorized lab environment.

Objectives

- Understand password hashing and its importance.
- Learn how password hashes are extracted.
- Explore John the Ripper for password auditing.
- Understand dictionary-based password attacks.
- Identify the security risks of weak passwords.
- Learn the importance of strong password practices.

Tools & Technologies

Tool| Purpose
John the Ripper| Password hash testing
Kali Linux| Cybersecurity testing environment
Wordlist| Dictionary-based password testing
Network Walks Lab| Practical learning environment

Methodology

1. Environment Setup

Prepared the cybersecurity testing environment and explored the required password auditing tools.

2. Password Hash Extraction

Learned how password hashes are extracted from password-protected files in the authorized lab environment.

3. Hash Analysis

Explored how password hashes are loaded and recognized by John the Ripper.

4. Dictionary-Based Testing

Studied how dictionary-based password testing works by comparing candidate passwords against extracted hashes.

5. Password Security Analysis

Analyzed the results and understood how weak passwords can be vulnerable to password-guessing techniques.

Key Learnings

Through this practical exercise, I gained knowledge about:

- Password hashing concepts.
- Password hash extraction.
- John the Ripper functionality.
- Dictionary-based password attacks.
- Password security vulnerabilities.
- The importance of strong and unique passwords.

Conclusion

This Week 3 practical exercise helped me strengthen my understanding of password security and password auditing techniques.

Working with John the Ripper provided valuable exposure to how password weaknesses can be identified in authorized cybersecurity testing environments.

I would like to thank Network Walks for providing this learning opportunity and practical cybersecurity experience.
